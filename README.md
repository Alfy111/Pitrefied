# Your Studio

A responsive single-page website with Home, About, Services, Contact, and Book
Online sections. The sticky header scrolls between sections and highlights the
section currently in view.

The business name, service descriptions, contact details, and booking destination
are starter copy to replace with your details.

## Run locally with live reload

1. Run `npm install` once to install the development dependencies.
2. Run `npm start` from the project folder.
3. Open `http://localhost:3000` on your computer. The page will reload when you
   save changes.
4. To view it on your phone, connect it to the same Wi-Fi and open
   `http://<your-computer-ip>:3000`.

## Photos

Put photos for the site in the `photos/` folder. Once you add them, tell me which
ones to use and I can reference them with paths such as `photos/my-photo.jpg`.

## Deploy to GitHub and Vercel

1. Create a GitHub repository and push these files to its default branch.
2. In Vercel, select **Add New Project** and import the GitHub repository.
3. Set the framework preset to **Other**. Leave the build command empty and set the output directory to `.`.
4. Select **Deploy**. Vercel will publish the site and provide its URL.

Future pushes to the connected branch will trigger a new deployment.
